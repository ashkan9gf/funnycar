# FunnyCarIR — فانی‌کار 🚗💨

> بازی موبایلی طنز فارسی — رانندگی کارتونی از نمای بالا با طنز روزمره خیابان‌های ایران.
>
> «پارک دوبل، بوق، چاله، تاکسی، پلیس بامزه... آبرو داری می‌برد یا می‌ریزی؟»

---

## ✨ این پروژه چیست؟

**FunnyCarIR** یک بازی اندرویدی (و وب) دوبعدی است که با تکنولوژی HTML5 + TypeScript ساخته می‌شود و در انتها با Capacitor به APK/AAB اندروید تبدیل می‌شود. تمام رابط بازی فارسی و راست‌به‌چپ (RTL) است و طنز آن از موقعیت‌های آشنای رانندگی روزمره ایرانی می‌آید — نه توهین، نه خشونت.

| مشخصه | مقدار |
|---|---|
| موتور | موتور اختصاصی سبک (Canvas 2D + TypeScript) |
| دوربین | Top-Down (از بالا) |
| کنترل | دکمه‌های لمسی + کیبورد برای تست دسکتاپ |
| زبان | فارسی کامل + اعداد فارسی |
| اینترنت | گیم‌پلی کاملاً آفلاین |
| فونت | وزیرمتن (مجوز آزاد OFL) |

## 🚀 اجرای بازی

بازی از پیش‌نمایش (Preview Panel) قابل اجراست. برای دسکتاپ از کیبورد: **جهت‌نما/WASD** = فرمان و گاز، **H** = بوق، **P** = Pause، **F** = نمایشگر FPS.

## 📁 ساختار پروژه

```text
src/game/          ← موتور بازی (TypeScript خالص، بدون وابستگی به React)
src/app/           ← پوسته رابط (Next.js) — منو، HUD فارسی RTL
public/assets/     ← Assetهای بازی (تصویر/صدا) — طبق ساختار رسمی
docs/              ← مستندات کامل فارسی ⭐
scripts/           ← ابزارها (اعتبارسنجی Asset، پردازش تصویر)
```

## 🧩 اصول ثابت پروژه (خلاصه سند مادر)

1. **توسعه مرحله‌ای** — هیچ فازی بدون تست و گزارش کامل نمی‌شود.
2. **Asset Pipeline** — منطق بازی هرگز به فایل تصویر وابسته نیست؛ جایگزینی Asset بدون تغییر کد انجام می‌شود.
3. **Placeholder شفاف** — هر Asset موقت برچسب دارد و قبل از Release لیستش چک می‌شود.
4. **طنز محترمانه** — فقط موقعیت، نه توهین.
5. **سبکی** — روی گوشی ضعیف هم روان؛ بودج حافظه در Inventory ثبت است.
6. **آفلاین** — گیم‌پلی به اینترنت نیاز ندارد.
