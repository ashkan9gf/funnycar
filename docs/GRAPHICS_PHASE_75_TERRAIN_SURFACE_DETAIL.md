# Phase 75 — بافت زمین حاشیهٔ جاده

## تغییر
- یک بافت رویه‌ای tileable برای خاک فشردهٔ گرم، سنگ‌ریزه‌های کم‌کنتراست و بوته/علف خشک پراکنده اضافه شد.
- زمین بزرگ صحنه از رنگ یکنواخت به متریال استاندارد با این بافت تغییر کرد.
- تکسچر یک‌بار ساخته و cache می‌شود؛ تکرار UV روی زمین انجام می‌شود و هندسهٔ اضافه یا هزینهٔ هر فریم ایجاد نمی‌کند.
- anisotropy روی حداکثر ۴ محدود شده تا هزینهٔ فیلتر روی موبایل کنترل شود.

## محدوده و محدودیت
این فاز عمق بصری زمین‌های دور از آسفالت را بهتر می‌کند، اما جایگزین terrain mesh واقعی، سنگ‌ریزه‌های هندسی نزدیک دوربین، یا ارزیابی هنری نیست. بافت با Math.random ساخته می‌شود، بنابراین الگوی دقیق آن در هر بار اجرا فرق دارد؛ تست بصری باید تکرارشدن الگو و seamها را بررسی کند.

## پذیرش
- CI باید build و تست‌های پروژه را بدون خطا تمام کند.
- روی دستگاه واقعی باید خط اتصال بافت، مصرف حافظه و FPS بررسی شود.
- نتیجهٔ این فاز به‌تنهایی به معنی تأیید AAA نیست.
